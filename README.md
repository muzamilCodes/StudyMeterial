# STUDY MATERIAL

This repository is split into two folders:

- [`frontend/`](C:/Users/warmu/Documents/Codex/2026-07-19/create-a-premium-modern-professional-educational/frontend) - Next.js app
- [`backend/`](C:/Users/warmu/Documents/Codex/2026-07-19/create-a-premium-modern-professional-educational/backend) - Express + MongoDB API

## Run

Frontend:

```bash
cd frontend
npm install
npm run dev
```

Backend:

```bash
cd backend
npm install
npm run dev
```

## Environment

- Frontend env: `frontend/.env.example`
- Backend env: `backend/.env.example`

Set `NEXT_PUBLIC_BACKEND_URL=http://localhost:4000` in frontend so auth and data pages talk to the backend folder.
